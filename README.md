# Задание 1: Заполнение двумерных массивов

### Текст задачи
Реализовать три способа заполнения двумерных массивов:
1. Массив (n × m): заполняется вручную с клавиатуры по столбцам снизу вверх.
2. Массив (n × n): заполняется случайными четырёхзначными числами, состоящими только из нечётных цифр (1, 3, 5, 7, 9).
3. Массив (n × n): заполнение по диагоналям.

### Алгоритм решения
Создан класс `Arr` с тремя перегруженными конструкторами:
1. `Arr(int n, int m)`: использует вложенные циклы. Внешний цикл проходит по столбцам (`j`), внутренний – по строкам снизу вверх (`i` от `n-1` до `0`). Предусмотрена возможность досрочного выхода по команде "exit".
2. `Arr(int n)`: генерирует числа, случайным образом выбирая 4 цифры из массива `{1, 3, 5, 7, 9}` и собирая их в четырёхзначное число (`d1*1000 + d2*100 + d3*10 + d4`).
3. `Arr(int n, string pattern)`: заполняет верхний левый треугольник нулями (`i + j < n - 1`). Для остальных элементов вычисляется номер диагонального слоя `layer = (i + j) - (n - 1)`. В зависимости от чётности слоя, ячейке присваивается значение `n - j` или `n - i`.

### Тестирование
Программа корректно обрабатывает ввод пользователя, генерирует числа из нечётных цифр и формирует диагональный паттерн.

# Задание 2:  Работа с двумерными массивами

### Текст задачи
В двумерном массиве n × m найти среднее арифметическое первого столбца и количество элементов в каждом из следующих столбцов, превышающих среднее арифметическое предыдущего столбца.

### Алгоритм решения
Реализован метод `CalculateAndCount()` в классе `Arr`:
1. Вычисляется сумма и среднее арифметическое элементов первого столбца (`j = 0`).
2. Запускается цикл по остальным столбцам (`j` от 1 до `cols - 1`).
3. Для каждого столбца `j` предварительно вычисляется среднее арифметическое предыдущего столбца (`j - 1`).
4. Вторым циклом подсчитывается количество элементов в текущем столбце `j`, которые строго больше этого среднего значения.

### Тестирование
Для тестовой матрицы 5×5 программа верно вычислила среднее первого столбца и корректно подсчитала количество элементов, превышающих среднее предыдущего столбца для каждого последующего.

# Задание 3: Работа с двумерными массивами как с матрицами

### Текст задачи
Выполнить расчет выражения $7 \cdot A \cdot (B^T - C)$, где $A$, $B$ и $C$ — заданные целочисленные матрицы, а $B^T$ — транспонированная матрица $B$.

### Алгоритм решения
В класс `Arr` добавлены методы для выполнения базовых матричных операций:
1. `Transpose()`: создает новую матрицу, меняя местами строки и столбцы исходной ($M[j, i] = M[i, j]$).
2. `Subtract(Arr other)`: выполняет поэлементное вычитание двух матриц одинаковой размерности.
3. `Multiply(Arr other)`: реализует алгоритм умножения матриц (строка на столбец) с проверкой совместимости размерностей.
4. `MultiplyByScalar(int scalar)`: умножает каждый элемент матрицы на скаляр.
5. Статический метод `CalculateExpression(Arr A, Arr B, Arr C)` последовательно вызывает эти методы для получения итогового результата.

### Тестирование
Программа успешно выполнила все этапы вычислений: транспонирование матрицы B, вычитание матрицы C, умножение на матрицу A и финальное умножение на скаляр 7. Результат выведен в консоль.

# Задание 4. Бинарные файлы

### Текст задачи
Найти разность максимального и минимального элементов заданного бинарного файла.

### Алгоритм решения
Класс `FileProcessor`, метод `TaskData()`:
1. Генерируется бинарный файл `data.bin`, содержащий 10 случайных чисел типа `double` (с помощью `BinaryWriter`).
2. Файл открывается через `BinaryReader`. Длина потока делится на `sizeof(double)` для определения количества элементов.
3. Данные считываются в массив, после чего с помощью LINQ (`numbers.Max()` и `numbers.Min()`) находятся экстремумы и выводится их разность.

### Тестирование

### Текст задачи
Подсчитать количество вхождений максимального элемента в текстовый файл.

1. Генерируется текстовый файл `numbers.txt`, где каждое случайное целое число записано на новой строке.

### Тестирование

### Текст задачи
Вычислить количество чётных элементов в текстовом файле.

### Алгоритм решения
Метод `TaskTextFileEvenCount()`:
1. Генерируется файл `numbers_multi.txt`, содержащий несколько строк. В каждой строке числа разделены символом `;`.
2. Файл читается построчно. Каждая строка разбивается на массив подстрок методом `Split(';')`.
3. Каждая подстрока преобразуется в число. Если число чётное (`num % 2 == 0`), счётчик `evenCount` увеличивается на 1.

# Задание 8. Текстовый файл

### Текст задачи
Переписать в другой файл строки, содержащие заданную комбинацию символов.

### Алгоритм решения
Метод `TaskFilterLinesBySubstring()`:
1. Генерируется исходный файл `source_text.txt` со случайными предложениями.
2. Пользователь вводит искомую подстроку.
3. Файл читается построчно. Для каждой строки проверяется наличие подстроки с помощью `line.IndexOf(substring, StringComparison.OrdinalIgnoreCase) >= 0` (поиск без учёта регистра).
4. Если подстрока найдена, строка записывается в результирующий файл `filtered_text.txt` с помощью `StreamWriter`.

### Тестирование
Программа успешно отфильтровала строки по заданному слову и записала только совпадающие строки в новый файл, выведя итоговое количество найденных строк.
